# 通用执行器插件 v0.3.0 验收记录

日期：2026-10-23。开发基线：`3803702`。本记录描述本次 Windows / Python 3.10 验证，不替代其他操作系统或真实 AI 服务验收。

## 已实现

- 通过 `agent_hub.executors` entry point 加载明确配置的独立插件，插件 API 为 v1；禁用和未选中的插件不导入。
- 通用命令桥接：UTF-8 JSON 请求文件、无隐式 shell 的参数数组、JSON/文本结果、显式续接和本地进程树停止。
- 能力与权限声明校验；不支持的模式和续接明确拒绝；命令桥接不伪装只读或操作系统沙箱。
- 审核端可选择支持 `text_only` 的配置实例，保留 Claude 历史证据身份、严格结果校验与有界返工。
- `plugins` 提供无导入的插件发现，`check-config` 提供不启动后台的本地配置诊断。
- 独立示例插件包、可执行包装模块、接入文档和跨平台 CI 定义。

## 独立审查与修复

独立审查发现两个 Important 问题，无 Critical 或 Minor 项。两项均先复现失败，再实现修复，最后通过上述完整回归；修复后未做第二轮独立审查。

1. 日志脱敏提前破坏命令 JSON，或改写 URL 形式的会话 ID。修复为从内存中的原始输出解析协议，日志独立脱敏；增加 Authorization 文本、URL 会话 ID、source_urls 及响应长度回归。
2. 插件结果中的非字符串对象键通过序列化检查，后续清理时造成工作线程退出、任务名额未释放。修复为递归校验纯 JSON 类型、字符串键、错误代码和错误详情；服务级回归确认非法结果成为终态失败并释放名额。

审查范围排除恶意的进程内插件：插件是用户明确安装的受信代码，契约校验不构成沙箱。真实外部提供商互通和其他操作系统执行尚无本次证据。

## 代码与设备数据分离

仓库保存代码、模板和文档；运行数据由每台设备的私有数据目录管理。插件状态位于该目录下各自的 `plugins/<instance>`；示例没有用户账号、个人工作路径或固定机器地址。新增 Git 忽略及打包排除规则覆盖本地配置、数据库、Cookie、日志、环境文件和运行目录。

已构建的两个 wheel 均通过运行文件/个人路径检查；没有把本机配置或账号复制进包。wheel/sdist 测试确认模拟私有文件和内容未进入包。安装后的环境可能含本地路径，因此应分发源代码或 wheel，不能复制虚拟环境或运行目录。

本次保留安装包：

- `local_agent_hub-0.3.0-py3-none-any.whl`（39 个归档项）
- `agent_hub_example_echo-1.0.0-py3-none-any.whl`（7 个归档项）

安装包与 SHA256SUMS 位于开发工作区的忽略目录 `dist/`，不写入 Git。源文件可重新构建；归档时间不同可导致 wheel 哈希变化。
