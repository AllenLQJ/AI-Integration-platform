# 可靠性与看板性能优化验证（2026-10-25）

## 变更

- 执行结果先写同目录临时文件，再原子替换；写入失败时在 SQLite 保存小型失败记录，始终释放执行名额。执行阶段与收尾阶段分离，收尾失败仍保留已知中断、取消及远端不确定证据。
- 工作项成员通过代表节点连接，替换全成员两两比较；界面上的显式关系边保持原有含义。
- 链详情在一个只读数据库快照内分批读取任务/验收元数据，使用带单任务 LIMIT 的索引事件查询，逐节点投影并立即执行链级裁剪；不读取链视图用不到的节点关系和产物详情。单节点检查器继续提供完整详情。补充 parent/review 表达式索引。
- 看板使用条件 GET；同一只读 SQLite 观察连接的 `PRAGMA data_version` 检测其他连接提交，包括不生成事件、不修改任务 updated 的验收更新。ETag 按进程和完整路由区分，先鉴权再返回 304；投影过程中发生提交时不发 ETag。关闭 HTTP 服务时释放观察连接。
- 浏览器仅在内存保留条件读取响应：最多 32 条、估算 UTF-16 文本总量 8 MiB、单条 2 MiB；会话变更或认证失败清空。缓存内容不写入浏览器持久化存储。
- 工作项标题统一脱敏，并支持转义 LIKE 通配符的字面搜索，保留同一成员上的 agent/state 过滤规则。
- 历史中断任务测试夹具在调度锁内完成 create/finish，避免历史状态的临时 queued 行被后台执行。保留原 GET-only 安全断言。
- 新增 Windows/Ubuntu 完整回归、前端测试和 wheel 资源检查工作流；原 Windows/macOS/Linux 插件矩阵保留。远程 CI 尚需推送后实际运行。

## 本机合成性能证据

这些数值来自本机临时 SQLite 合成数据，不代表真实第三方模型或生产负载的性能。

- 每工作项 10 个任务；图构建取三次中位数：1,000 个任务 19.4 ms，2,000 个任务 24.9 ms，4,000 个任务 56.5 ms。优化前对应约 313.1 / 814.3 / 3476.5 ms。
- 50 节点详情：13 次 SELECT；原审查样本为 407 次 SELECT（新增回归夹具的旧实现为 457 次）。
- 10 节点、每节点 50 条、每条 10k 字符消息：最终投影的 tracemalloc 峰值约 4.35 MiB，输出消息 100 条；第一版批量投影约 17.3 MiB。回归测试设 12 MiB 上限，防止再次暂存整链历史。
