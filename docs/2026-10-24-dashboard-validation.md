# 只读看板首版验收记录

日期：2026-10-24。开发基线：`f9f1d2c`，功能分支：`codex/agent-dashboard`。

## 实现范围

- 用户选定的 A 三栏工作空间：任务列表、协作记录、任务详情；窄屏任务与详情抽屉。
- 独立 ES 模块前端、版本化只读展示 API、安装包内静态资源，运行时无需 Node.js。
- 关键词、执行状态与动态执行器筛选、服务器分页；任务列表自动更新，选中任务以事件游标和详情查询更新。
- 区分任务输入、记录片段与最终结果，标注来源和截断状态；明确区分执行状态和验收状态。
- 根据已保存的会话和审核字段展示续接、新执行器会话及审核关系。
- 一次性登录票据与独立 HttpOnly 只读会话；Cookie 按服务端口隔离，支持同一浏览器同时查看多个数据目录的 Hub。

## 验证边界

浏览器验收连接真实 HTTP 服务与持久化存储，但数据是独立临时数据库内的合成测试记录；未启动真实模型调用，未重新验收各执行器的远端行为，未重启日常使用的 Hub。测试数据、票据、日志和截图不进入 Python 分发包。

第一版展示 Hub 已记录的信息。历史数据未记录的 Agent 派发调用者、完整工具输入输出或截断消息不能由看板恢复；没有新增派发追踪协议。第一版不包含任务修改操作或公网部署。

本轮实测平台是 Windows；平台条件跳过不视为通过，其他操作系统安装与浏览器运行未在本轮实测。功能分支保留供审阅，合并与发布另行处理。
