## 实施决策

- 工作在 Codex 托管的独立 worktree；主目录保留原有 Muse 与工具。产品不依赖这些文件的相对位置，使用配置绝对路径。
- 既有可续接工作区与新任务共享互斥锁；不自动删任务 worktree。
- 任务结果在私有目录 JSON 文件保存，数据库仅存引用；事件做脱敏后落盘。
- Windows 后台通过 WMI 在 MCP SDK Job 之外启动；执行器反而放入各自 kill-on-close Job，父进程退出或服务崩溃时清理后代。
- Muse SDK 运行在独立 worker，后台能强制停止整个本地进程树，避免 SDK 清理延迟造成任务期限失效；这不代表远端取消。
- 崩溃后无法核对旧执行状态时隔离工作区，拒绝直接续接。代价：需要用户人工核对后新建任务，优先避免两轮同时写文件。
- Codex Windows 使用本机已通过的 MXC，保持只读/工作区写权限，不改全局 sandbox 设置。elevated 在用户私有数据目录里不能完成真实修改，不以全权限绕过。
- CLI 失败的退出码、日志引用与部分差异已补齐并验证；后台退出与测试目录清理存在短暂句柄释放延迟，集成测试额外等待。
