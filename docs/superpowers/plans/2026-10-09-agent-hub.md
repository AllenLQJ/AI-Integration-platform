**目标：** 实现 Windows 本地任务 Hub，统一调用 Codex、Claude、Muse。

**架构：** stdio MCP → 带私有令牌的回环 HTTP 服务 → SQLite 与后台线程 → 执行器。服务仅一个实例，恢复时不重发运行任务。

**技术：** Python 3.10、SQLite、标准库 HTTP、MCP SDK 1.30.0、unittest。

**设计依据：** ../specs/2026-10-09-agent-hub-design.md

## 全局约束

- 三个适配器，默认全局并发 2、每执行器 1；期限 10–7200 秒，默认 1800。
- 模式 read_only / edit_worktree；任务和日志在用户私有数据目录，凭证不进源码。
- 不自动合并、删除 worktree；不公开端口；不自动重发未知发送任务。
- CLI 使用参数数组、环境允许列表、专用 MCP 配置；Claude 当前明确为 CCR/API 模式。
- Mac / DeepSeek harness 不宣称实测。Muse 仅文本任务，取消不声称远端停止。

## 审阅重点

重启与发送竞态、取消后成功覆盖、同工作区多轮并行、HTTP 非回环访问、日志泄漏与分页大小、CLI MCP 递归、Muse 接受确认被当作最终结果。

## 接口预检查

Store → Service：dict 任务结构与原子状态转换；Service → adapters：取消事件与 deadline，adapter 返回 answer/session_id/artifacts。
Service → HTTP → MCP：固定 tool + arguments 请求，HubError(code,message) 结构化返回。
后台重启：queued 保留；running/cancelling → interrupted，不杀旧 PID，不自动重发。
