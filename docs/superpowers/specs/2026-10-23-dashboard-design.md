# Agent Hub 独立前端看板设计

状态：A 方案只读首版已实现并通过 2026-10-24 本轮验收；测试范围和未验收边界见实现计划与验收记录。

## 用户已确认

- 独立前端通过统一 API 接入 Hub。
- 界面选择 A：左侧任务列表、中间协作对话、右侧任务详情。
- Apple 式极简风格：简约、留白清晰、操作自然；窄屏以抽屉承载侧栏。
- 保持模块解耦与跨设备通用性，供其他人安装使用。
- 分发内容不包含个人机器路径、账号、凭据、真实任务记录或日志。
- 必要时可使用子代理处理独立开发工作。
- 2026-10-23 曾暂停以切换模型；用户随后明确要求继续开发。

## 目的与第一版建议范围

让使用者看清已有任务由哪个执行器处理、执行到了哪一步、提交了什么内容、返回了什么结果，并区分执行完成和验收通过。

首版范围如下；实现与验证结果以验收记录为准：

- 只读任务列表：按执行器、状态和关键词筛选，后端分页。
- 工作项详情：任务/执行尝试、审核关联、执行与验收状态、能力摘要。
- 协作对话：任务输入、已记录消息、最终结果；避免重复展示同一结果。
- 执行事件：状态、工具摘要及可展开的原始自定义事件。
- 展示真实来源的续接、换执行器、审核关系；初版可用简洁的步骤条/关联列表。
- 增量更新、刷新恢复、明确的断连和加载状态。
- 暂不在第一版加入任务派发、取消、总控接管或远程公开部署。

## 界面方向

A 三栏工作台已被用户选中。B 以协作图为主，C 以对话阅读为主，两者保留为交互参考，不替代 A。

桌面端保留三个主要区域。任务列表用于快速切换；对话区占主要宽度；详情区展示上下文、参与者与验收，不重复堆砌日志。次要信息按需展开。窄屏时侧栏改为抽屉，保证主要内容无横向溢出。支持键盘操作、清晰焦点和减少动画偏好。

原型只使用合成数据，其中的品牌、任务、时间、消息、文件和验收结论不是实时 Hub 数据，也不是产品验收证据。

## 实现边界

### 前后端分离

建议使用独立前端模块和版本化展示 API，允许同仓库分目录管理，不要求另建 Git 仓库。前端只依赖展示 DTO；后端投影模块负责将 Hub 数据映射为页面需要的形状。生产构建静态资源可随 Python 包分发，最终用户不必安装前端构建工具。

实现采用无第三方依赖的原生 ES 模块和 CSS，随 Python 包分发，无需 Node.js 运行时或构建工具。React + TypeScript 是早期候选方案，未作为首版依赖。首版以事件 seq 游标定时增量读取，不引入 WebSocket。

### 服务生命周期与安全

- 展示 API 复用已有 Hub Service/Store 实例，不能为看板另构造一个 Service 读取同一数据库；其初始化会 recover 任务并启动调度。
- 不将 `connection.json` 中的管理 token 交给前端，不在 URL、HTML 或浏览器存储中放置它。
- 为浏览器设计范围明确的只读会话。现有单工作项 cookie 不自动授权全局列表或独立审核任务。
- 打开看板不调用 `claim_controller`，不改变已有 controller epoch。
- 展示字段采用显式白名单、脱敏与访问校验，不原样透传任务或执行器 diagnose 字典。
- 执行器返回内容按不可信文本渲染；若支持 Markdown，采用受限安全渲染。

### 数据真实性

- `parent_id` 是续接/返工/换执行器的尝试链，不等于 Agent 派发子任务。
- 独立审核关联由 `review_of` 和审核记录表达，不属于同一 parent 尝试链。
- `request_id` 是幂等键，controller 租约也不是聊天身份，不可推断调用者。
- 真正的派发追踪需要新增明确字段；历史记录缺失时显示未知，不能根据提示词猜测。
- 普通事件不会更新任务 updated，增量查询必须使用事件 seq。
- 部分 CLI 消息会截断；工具事件不保证完整输入输出。页面应标注来源与完整性。
- command v1 不解析 stdout 为 CLI/Hub 过程事件。看板不得为了丰富显示而破坏这个协议边界。
- 插件自定义事件保留原始类型；展示归一化放在投影层，避免更改执行器协议。
- 执行器实例和能力动态加载，不把演示中的 Codex/Claude 名单硬编码进业务逻辑。

### 建议的最小展示契约

- TaskSummary：任务与工作项 ID、执行器实例、模式、时间、执行/验收/综合状态、工作空间显示名。
- Message：稳定 ID、任务 ID、角色、文本、时间、来源与完整性。任务输入/结果和事件消息需要有明确去重策略。
- TimelineEvent：任务 ID、seq、类型、时间、脱敏内容和可选显示提示。
- Relation：起止任务 ID、关系类型、证据来源；不能把未经记录的派发关系当作已知事实。

具体接口、分页、消息来源与只读会话约定见 [实现计划](../plans/2026-10-23-dashboard.md) 和 [使用文档](../../dashboard.md)。
